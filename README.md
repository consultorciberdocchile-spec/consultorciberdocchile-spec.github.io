# ILR · Ciberseguridad en Educación

Sitio de la consultoría, publicado con GitHub Pages.

- `index.html` — el sitio completo, en un solo archivo.
- `presentaciones/` — una carpeta por presentación: láminas, PDF y el .pptx original.
- `.nojekyll` — evita que GitHub reprocese los archivos.

## Cómo se actualiza

No se edita nada aquí. Se trabaja sobre `ILR_Ciberseguridad_Educacion_vf.html`
en la carpeta de arriba y luego se ejecuta **`ACTUALIZAR_SITIO_WEB.bat`**, que
copia la versión nueva, la sube y deja el sitio al día en uno o dos minutos.

**La firma manuscrita (`privado/`) no se sube nunca.** Está excluida en `.gitignore`.
